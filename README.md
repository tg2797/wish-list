# 欲しいものリスト 🎁 → (アイコンは全部SVGに置き換え済み)

スマホ（とくにiPhone）で気持ちよく使える、ほしいもの管理アプリ。
**1つのHTMLファイルだけ**で動きます。サーバー不要・オフラインOK・データは端末内（localStorage）に保存。

## 使い方

- そのまま `index.html` をブラウザで開くだけ。
- iPhoneでは Safari で開く →「共有」→「ホーム画面に追加」でアプリのように使えます。
- GitHub Pages で公開すれば、URLを開くだけで使えます（Settings → Pages → Branch を選ぶだけ）。

## できること

- ほしいものの追加 / 編集 / 削除（**左スワイプ**で削除）
- 値段・カテゴリ・優先度（高/中/低）・メモ・リンクを登録
- ステータス切り替え（すべて / 未購入 / 購入済み）
- カテゴリの絞り込み・追加・色変更・削除
- 並び替え（優先度順 / カテゴリ順 / 価格が高い順 / 安い順）
- 合計金額・達成率の自動集計
- ダークモード対応（端末設定に追従）

## このアップデートでやったこと

### 1. アイコンをすべて「絵（SVG）」に
端末ごとに見た目が変わる絵文字・記号（🛍️ ✨ ↕ ⚙ ⚑ ▦ ↓ ↑ ✓ › ↗ ＋）を、
すべて自前のインラインSVGアイコンに統一。どの端末でも同じ、すっきりした見た目になります。

### 2. バグ修正
- **URLの安全性**: `javascript:` などの危険なスキームを拒否。`example.com` のようにスキームを省略しても自動で `https://` を補完。
- **リンクの誤タップ**: リンク内のアイコンをタップすると編集画面が開いてしまう不具合を修正。
- **壊れたデータの防御**: 保存データが壊れていてもクラッシュせず読み込めるよう正規化処理を追加。
- **入力チェック**: 名前の必須チェック、URL形式チェックをエラー表示付きで実装。
- **削除済みカテゴリ**: 絞り込み中のカテゴリを削除しても表示が崩れないように。
- **複数タブ同期**: 別タブでの変更を自動反映。

## テスト

Playwright による自動E2Eテスト（30項目）を同梱しています。

```bash
node test.mjs
```

表示・追加・編集・削除（スワイプ）・フィルタ・並び替え・カテゴリ管理・
入力バリデーション・XSS対策・永続化・絵文字不使用 などを検証します。
